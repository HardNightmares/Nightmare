Повстанческий Nightmare — готовый сайт-визитка (v2.0)
=====================================================

ЧТО ВНУТРИ АРХИВА:
- index.html             : главная страница
- config.js              : все настройки (ники, ссылки, BIO, режим звука)
- styles.css             : дизайн (обсидиановое стекло, 12 искр, адаптив)
- js/*.js                : 5 модулей (плеер, виджеты BIO, курсор, достижения, терминал)
- assets/background.mp4  : твоё оригинальное видео БЕЗ искажений (со звуком!)
- assets/avatar.png      : твоя оригинальная аватарка БЕЗ изменений

1. БЫСТРЫЙ ЗАПУСК НА КОМПЬЮТЕРЕ:
   Распакуй архив в любую папку и просто дважды кликни по файлу index.html.
   Нажми на экран "CLICK TO ENTER" — запустится видео и его фоновая музыка.

2. КАК ВЫЛОЖИТЬ САЙТ В ИНТЕРНЕТ 24/7 БЕСПЛАТНО:
   Вариант А (Netlify Drop — за 30 секунд):
   - Открой https://app.netlify.com/drop
   - Перетащи распакованную папку nightmare-bio прямо в окно браузера.
   - Сайт сразу заработает круглосуточно по твоей ссылке.

   Вариант Б (GitHub Pages — навсегда и бесплатно):
   - Создай публичный репозиторий на https://github.com
   - Загрузи внутрь все файлы и папки из nightmare-bio (сохраняя папки js/ и assets/).
   - В настройках репозитория: Settings -> Pages -> Branch: main -> Save.

3. КАК ПОТОМ ДОБАВИТЬ ОТДЕЛЬНЫЕ ПЕСНИ (MP3):
   - Положи файл yaderi.mp3 в папку assets/ (или укажи прямую ссылку в streamUrl).
   - Открой config.js и поменяй строку:
       audioMode: 'video'
     на:
       audioMode: 'tracks'

4. СОВЕТ ПО КОДЕКУ ВИДЕО (ЕСЛИ ВДРУГ У КОГО-ТО В FIREFOX ЧЁРНЫЙ ФОН):
   Твоё исходное видео записано в кодеке H.265 (HEVC / hvc1). Chrome, Safari, Edge и
   телефоны играют его отлично, но старый Firefox на ПК иногда требует H.264.
   Если понадобится перекодировать без потери качества, выполни команду FFmpeg:
   ffmpeg -i assets/background.mp4 -c:v libx264 -crf 17 -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 192k assets/background_h264.mp4
